# Beta interview script (BETA-003)

A ~30-minute conversation, run after the artist has set up their studio (and
ideally run a request through it). Goal: learn where the real workflow breaks,
not to demo. **Watch more than you ask.** Let silences sit.

## Ground rules (for the interviewer)

- You're testing the product, not the artist. Say so.
- Don't defend or explain the UI — if they're confused, that's data.
- Ask "why" and "what did you expect?", never "do you like it?".
- Record (with consent) or take verbatim notes. Capture their words, not your paraphrase.

## 0. Warm-up (3 min)

- How do you handle commissions today, end to end? Walk me through your last one.
- What part of that is the most annoying / where do things fall through?

## 1. First impression (3 min) — before they touch it

- When you landed on Mirae, what did you think it was for?
- Who did it feel like it was built for?

## 2. Studio setup — observed (10 min) — share screen, they drive

Say: "Set up your studio like you'd actually use it. Think out loud. I won't help
unless you're fully stuck." Then watch silently. Note every hesitation.

- Where did they pause or look lost?
- Did they understand: profile vs portfolio vs links vs commission types?
- Did the onboarding tour/checklist help or annoy?
- Did anything make them go "oh nice"?
- What did they try to do that wasn't possible?

## 3. The request → delivery loop (7 min)

- Send yourself a request from your own public page. What did that feel like as
  the client?
- Now handle it as the artist: quote it, move it through the queue, deliver it.
- Open the client portal — would you send this to a real client? What's missing?
- Revisions: does this match how you actually handle changes?

## 4. Value + gaps (5 min)

- If this existed and worked perfectly, would it replace what you do today? What
  would still be missing?
- What would make you *not* use it?
- Would you pay for this? (Don't lead.) What would feel fair? For what exactly?
- What's the one thing you'd fix first?

## 5. Close (2 min)

- Can I follow up as we ship fixes?
- Would you run a real commission through it this month?
- Anyone else you'd recommend I talk to?

## After each interview (fill immediately)

- Top 3 friction points (with the exact screen/step)
- Top 1 "aha" moment
- Would-they-actually-use-it: yes / maybe / no + why
- Willingness to pay signal
- New issues → log in the tracker (see [`BUG_TRIAGE.md`](./BUG_TRIAGE.md))
- Quotes worth keeping (verbatim)
