# Beta tester profiles (BETA-001)

Who we want in the closed beta (5–10 artists) and why. The goal is to validate
the full loop — public studio → request → quote → queue → delivery → client
portal — with real artists and, ideally, real clients.

## Target: the "ideal early Mirae artist"

- **Takes commissions today** and already manages them manually (DMs, spreadsheet,
  Trello, Notion, a ToS doc). Feels the pain we remove.
- **Brings their own audience** (X/Twitter, Instagram, Bluesky, TikTok, a Discord).
  Mirae is Calendly-not-VGen — we don't find clients, we structure the ones they
  already attract.
- **Digital work** — illustration, character art, emotes, VTuber assets, reference
  sheets, concept art, stickers. Fast, image-heavy portfolios.
- **Solo or very small.** No studio ops team; they are the ops.
- **Some volume** — enough requests that structure matters (a few/month+), but not
  so slammed they can't try something new.

## Segments to cover (aim for a spread)

| Segment | Why include |
| --- | --- |
| Illustrator / character artist | Core use case; portfolio-first matters most |
| VTuber / emote / Twitch asset artist | Heavy request volume, revision-heavy, Discord-native |
| Reference-sheet / ych artist | Fixed-price "Fiverr-like" request flow is central |
| Concept / editorial | Higher price points, quote + milestone flow |
| Newer artist opening commissions | Tests onboarding + studio setup from zero |

## Explicitly out of scope for this beta

- Agencies / multi-artist studios (different ops model).
- Physical-goods sellers, print shops (fulfilment/shipping, not our loop).
- Anyone wanting a marketplace / to be discovered — Mirae doesn't do discovery.
- Purely free / non-commission artists (nothing to manage).

## Recruiting target

- **5–10** artists, spread across the segments above.
- Mix of platforms so we see different audience→request behaviour.
- At least 2–3 who can run a **real** commission through it during the beta
  (not just a dry run), so the client portal gets exercised by an actual client.

## Selection checklist (per candidate)

- [ ] Actively takes commissions
- [ ] Owns an audience / traffic source
- [ ] Digital, image-based work
- [ ] Willing to do a 30-min setup + a short interview
- [ ] Ideally has a live commission to run through it
